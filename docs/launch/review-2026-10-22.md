# Review of the agent-adoption and launch changes

Reviewed commits `68653cb` and `1f5d5d1`. This review covers the added source resolver, public API and CLI integration, plugin defaults, GitHub Action, schemas and agent documentation, the Observatory content diff, and the launch renderer and instructions. It is not an audit of every adapter or rule in the repository.

## Findings addressed

1. **Incorrect Hub revision under some cache layouts.** `_snapshot_revision` selected the first path segment named `snapshots`. A cache under a directory with that name could report a cache-folder name as a dataset revision. The resolver now verifies that the final snapshot directory is a 40-character commit under its immediate `snapshots` parent. An unexpected client return fails rather than labeling a mutable branch as resolved provenance. Regression tests cover both cases.
2. **The advertised installation did not provide the advertised demo.** The video showed `pip install physlint`, while the demo was only in source and the package remained 0.3.2. The clip now directs viewers to the README, which explicitly separates released and staged features and supplies an existing pinned source commit that includes the demo. No package version or historical evidence was rewritten.
3. **Video evidence could drift from the product.** The earlier renderer hardcoded pass counts, sample location, and remediation. The replacement runs the demo, reads its actual action samples, and extracts the finding. It also writes the displayed evidence to JSON and stops if the expected one-defect demonstration changes.
4. **Video delivery and readability.** The old clip lasted 45 seconds and shrank screenshots and a compatibility table into slides. The replacement is 18 seconds, uses large native text and a sample scan, and renders a separate 4:5 layout. MP4 `faststart` is now passed to the container, where it belongs, rather than to the H.264 encoder.

## Useful work retained

The typed API, structured reports, revision-qualified source syntax, offline option, plugin opt-in at the public API/CLI boundary, and reusable Action are useful foundations. Replacing them wholesale would add churn without addressing these findings.

The Action's validation shell was exercised locally with a corrupted synthetic dataset. It produced all four report formats and recorded exit code 1 for the final enforcement step. Hosted artifact upload and SARIF ingestion still depend on the caller's GitHub environment and permissions.

## Boundaries that users should know

- “Safe” controls configuration-declared Python plugins. Installed entry-point plugins still run; dataset configuration can still select rules, thresholds, cache paths, and report paths. It is not a filesystem or process sandbox. Use a reviewed explicit config when checking an untrusted dataset in CI.
- JSON errors from handled runtime failures follow the published error schema. Command-parser errors, such as an unknown option or missing argument, still use Typer's normal diagnostic output; agents should handle non-JSON stderr on exit 2.
- The reusable agent skill now handles that parser-error exception and describes the plugin trust boundary, matching the operating guide.
- Version 0.4.0 remains unreleased. The review does not establish new adapter coverage or rerun the public real-data evidence suite.
- The media depicts a controlled synthetic corruption and edited timing. It does not show a real robot, measured GPU savings, or improved training outcomes.

The new marketing plan focuses on dataset trials and repeat use. Public posts and maintainer messages are prepared material; none have been sent by this review.

## Verification

All 96 tests pass, with 86% source coverage. Ruff and strict mypy pass. Both final videos decode to exactly 540 frames at 30 fps (18 seconds); their MP4 headers precede video data for progressive playback. All four scenes were visually checked in both aspect ratios. A clean install of PyPI 0.3.2 confirmed that `demo` is absent; a separate clean install from the README's pinned source commit ran the demo successfully.
